# DevtaSoft – Software House Website

DevtaSoft is a modern, responsive, and visually engaging software house website designed to showcase digital services, products, projects, and company information.

The website features a clean and professional UI built using DevtaSoft’s brand color palette:

- 🟠 Primary Orange: `#FF8706`
- 🩵 Secondary Cyan: `#53E5E7`
- 🟣 Dark Indigo: `#2A285F`

## ✨ Features

- Modern and responsive landing page
- Professional About Us page
- Detailed Services page
- Product showcase
- Interactive Portfolio page
- Large project mockups for better project presentation
- Portfolio category filters
- Contact and project inquiry section
- Smooth animations and hover effects
- Mobile, tablet, and desktop responsive design
- Clean and user-friendly UI/UX

## 🎨 Design Approach

The website follows a clean, modern, and minimal design approach. It uses generous whitespace, smooth interactions, subtle shadows, modern typography, and consistent branding to create a premium digital experience.

DevtaSoft is optimized for:
